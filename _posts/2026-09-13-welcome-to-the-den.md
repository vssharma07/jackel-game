This is the first post on a Jekyll blog with no database and no server to manage —
just Markdown files in a Git repo. Every push to `main` runs a GitHub Actions
workflow that builds the site with Jekyll and deploys the result to GitHub Pages.

No CMS, no hosting bill, no server to patch. Write a Markdown file, push, and the
site rebuilds itself.
